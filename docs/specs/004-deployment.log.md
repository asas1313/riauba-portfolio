Reviewer returned CHANGES REQUESTED with 1 BLOCKER + 2 SHOULD FIX + 2 NITs; all fixed, test-first where applicable. **BLOCKER**: `make smoke ENV=staging`/`ENV=production` in the deploy workflows never received `SHA=`, so AC-8's `/version.txt` comparison was dead code — a step-level `env:` set on the preceding `infra/deploy.sh` step doesn't carry over to the sibling `make smoke` step.
