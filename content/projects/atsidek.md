People on individual activity (IV) in Lithuania struggle to know how much to set aside for income tax
and social contributions. Atsidėk calculates it and an AI assistant explains the numbers.

- Spring Boot calculation engine with a JSON API for comparisons.
- Python service using the Claude API for the conversational assistant.
- Separate staging and production environments.
